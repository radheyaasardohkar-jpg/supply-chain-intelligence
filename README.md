# Supply Chain Intelligence Platform

## Overview
An end-to-end analytics platform for supply chain visibility, demand forecasting, and inventory optimization.

## Objectives
- Validate and prepare sales and inventory data.
- Build SQL models and business KPIs.
- Forecast product demand.
- Estimate reorder points and safety stock.
- Develop an interactive Streamlit dashboard.
- Test and document the data pipeline.

## Technology Stack
- Python, pandas, NumPy
- SQL and SQLAlchemy
- scikit-learn and statsmodels
- Plotly and Streamlit
- pytest

## Project Status
Initial project setup completed. Data acquisition and exploration are next.
